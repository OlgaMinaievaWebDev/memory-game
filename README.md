# Memory Game

A browser-based card-matching game. Reveal two cards at a time, remember their positions, and find all eight matching emoji pairs in as few moves as possible.

## Features

- Sixteen shuffled cards with eight matching pairs
- Move and matched-pair counters
- New game without reloading the page
- Victory modal with the final score
- Persistent top-ten leaderboard stored in `localStorage`
- Responsive layout and keyboard-accessible controls

## Technologies

- HTML5
- CSS3
- JavaScript (ES modules)
- Web Storage API

## Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/OlgaMinaievaWebDev/memory-game.git
   ```

2. Open the project directory in VS Code.
3. Open `index.html` with Live Server.

## How to play

1. Select a card to reveal its emoji.
2. Select a second card.
3. Matching cards remain open; different cards turn face-down again.
4. Match all eight pairs to finish the game and save your result.
